# 🎵 BeatPay Virtual - Music Pro (Evaluación 1)

Sistema de pagos digital y tarjeta virtual estilo Visa orientado a la administración de fondos, recargas y pagos de entradas para conciertos y eventos de la gira de Music Pro.

---

## 👥 Datos del Proyecto

* **Institución:** Inacap

---

## 🚀 Características Principales del Sistema
* **Autenticación Simulada:** Módulo de acceso y control de credenciales.
* **Dashboard Fintech:** Panel principal interactivo con temática oscura (*Dark Mode*).
* **Tarjeta Virtual Visa (Mock Data):** Visualización del estado, número enmascarado y saldo disponible en moneda local (CLP).
* **Carga de Fondos:** Formulario interactivo para sumar saldo simulado.
* **Cartelera de Conciertos & Pagos:** Listado de eventos con validación de saldo en tiempo real.
* **Historial de Transacciones:** Tabla detallada de movimientos y pagos procesados.

---

## 🛠️ Tecnologías Utilizadas
* **Backend:** Python, Django framework.
* **Frontend / UI:** HTML5, Tailwind CSS.
* **Arquitectura:** Datos simulados (*Mock Data*) en memoria.
