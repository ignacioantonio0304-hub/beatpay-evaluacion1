# 🎵 BeatPay Virtual - Music Pro (Evaluación 2)

Sistema de pagos digital y tarjeta virtual estilo Visa orientado a la administración de fondos, recargas y pagos de entradas para conciertos y eventos de la gira de Music Pro, implementado con una arquitectura backend robusta en Django y base de datos relacional.

## 🚀 Características Principales (Evolución Evaluación 2)
- **Base de Datos Relacional (SQLite):** Migración completa a modelos persistentes (`User`, `TarjetaVirtual`, `Transaccion`).
- **Panel de Administración Django:** Gestión centralizada y segura de usuarios, tarjetas y registros financieros.
- **Población Masiva con Faker:** Script automatizado (`faker_data.py`) para la generación e inserción de 100 registros de prueba coherentes.
- **Dashboard Fintech:** Panel principal interactivo con temática oscura (*Dark Mode*).
- **Gestión de Tarjeta Virtual y Pagos:** Control de saldos, estados de tarjeta y registro de transacciones en tiempo real.

---

## 🛠️ Tecnologías Utilizadas
- **Backend:** Python, Django Framework (ORM, Migrations, Admin).
- **Generación de Datos:** Biblioteca `Faker`.
- **Frontend / UI:** HTML5, Tailwind CSS.
- **Base de Datos:** SQLite.
